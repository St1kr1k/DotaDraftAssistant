# Dota Draft Assistant (MVP vertical slice)

Аналитический overlay для драфта Dota 2. Приложение само видит экран выбора героев (computer vision), отслеживает пики и даёт рекомендации с объяснением **почему**. Вручную вводится только ваш профиль.

Архитектура и выбор стека описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

> ⚠️ **Статус.** Код написан без возможности сборки: в среде разработки не было .NET SDK и доступа к OpenDota/Steam. Алгоритм распознавания проверен Python-прототипом на синтетических данных (`tools/prototype`). Первая сборка, `dotnet test` и проверка на реальных скриншотах — первые шаги на вашей машине (см. ниже). Если сборка упадёт, пришлите вывод: правки будут точечными.

## Требования
- Windows 10 2004+ / Windows 11, .NET 8 SDK
- Dota 2 в режиме **Borderless Window / Borderless Fullscreen** (в exclusive fullscreen GDI-захват может вернуть чёрный кадр)

## Для друзей: установка
**С выбором папки:** https://github.com/St1kr1k/DotaDraftAssistant/releases/latest/download/DotaDraftAssistant-Installer.exe — маленький установщик: выбираете папку, он скачивает последнюю версию и ставит её туда.

**В одну кнопку:** https://github.com/St1kr1k/DotaDraftAssistant/releases/latest/download/DotaDraftAssistant-win-Setup.exe — ставит сразу в `%LocalAppData%\DotaDraftAssistant`.

Права администратора не нужны, ярлык создаётся, программа запускается сама. Обновления скачиваются автоматически и ставятся после закрытия приложения. Удаляется программа через «Приложения» Windows.

> Файл не подписан цифровой подписью, поэтому Windows SmartScreen покажет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае». Чтобы убрать это предупреждение, нужен сертификат подписи кода (платный).

### Как выпускаются версии
Код лежит на GitHub. Workflow `.github/workflows/release.yml` на каждый push в `main` (и раз в неделю, чтобы обновить статистику патча) делает следующее:
1. собирает проект и прогоняет тесты на Windows-сервере GitHub;
2. скачивает героев и статистику патча;
3. собирает установщик (Velopack) и публикует его в Releases под версией `1.0.<номер сборки>`.

Установленные копии сами подтягивают новую версию.

## Сборка у себя: самый простой способ
Дважды щёлкните **`build.bat`**. Скрипт сам установит .NET 8 SDK (если его нет), скачает данные героев и соберёт один файл `release\DotaDraftAssistant.exe`. Дальше запускайте только его.

## Первый запуск вручную

```powershell
# 1. Данные героев, портреты, статистика патча и матчапы (~3 минуты из-за лимита OpenDota 60 запросов/мин)
dotnet run --project tools/DataTool -- fetch --out data

# 2. Тесты
dotnet test

# 3. Приложение (данные из ./data копируются рядом с exe при сборке)
dotnet run --project src/Presentation
```

При первом запуске откроется окно профиля: позиция, основной герой, комфортные герои и герои, которых вы избегаете.

## Калибровка (один раз на разрешение)
1. Зайдите в лобби или матч и дождитесь экрана выбора героев. Можно взять скриншот этого экрана (F12 в Steam).
2. **Ctrl+Shift+D** → overlay станет интерактивным → **Калибровка**.
3. Нажмите «Захватить окно Dota 2» (или «Открыть скриншот…»). Обведите 1-й и 5-й слоты Radiant, затем 1-й и 5-й слоты Dire. Последним шагом обведите статичный элемент, который есть только на экране драфта (рамку панели без таймера). Это «сигнатура»: с ней драфт обнаруживается сразу, без неё — только с первого пика.
4. Если на кадре все слоты пустые, отметьте галочку — сохранится эталон пустого слота.
5. Проверьте пунктирные слоты и нажмите «Сохранить».

Разметка лежит в `%APPDATA%\DotaDraftAssistant\layout\` в нормализованных координатах.

## Проверка распознавания на скриншоте
```powershell
dotnet run --project tools/DataTool -- check-layout --screenshot C:\shots\draft.jpg --data data --out debug
```
Команда выводит для каждого слота статус, уверенность и топ-3 кандидатов, а также сохраняет `debug/annotated.png` и вырезки слотов.
Если героя путает или пишет `unknown`, обычно портрет в слоте обрезан иначе, чем арт с CDN. Добавьте вырезку как шаблон:
```powershell
dotnet run --project tools/DataTool -- add-template --screenshot C:\shots\draft.jpg --slot Dire-Pick-2 --hero "Axe" --data data
```
После этого пересоберите приложение, чтобы новые шаблоны скопировались.

## GSI (рекомендуется)
Официальный Valve Game State Integration сообщает фазу игры, вашу сторону и вашего героя. С ним переключатель стороны не нужен.
1. Скопируйте `gsi/gamestate_integration_draftassistant.cfg` в
   `…\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\` (папку создайте, если её нет).
2. В параметрах запуска Dota 2 в Steam добавьте `-gamestateintegration`.

Без GSI выберите сторону вручную: Ctrl+Shift+D → «Сторона».

## Горячие клавиши
| | |
|---|---|
| Ctrl+Shift+D | интерактивный режим вкл/выкл (по умолчанию overlay click-through) |
| Ctrl+Shift+O | скрыть / показать overlay |

## Настройки
`%APPDATA%\DotaDraftAssistant\settings.json` создаётся при первом запуске. В нём настраиваются веса компонентов (`Scoring.Weights`), бракеты меты, частота анализа, пороги распознавания и подтверждения. Лог пишется в `draft-assistant.log` в той же папке.

## Безопасность
Только чтение пикселей экрана, официальный GSI и публичные API. Приложение не читает память процесса, ничего не инжектит, не нажимает клавиши и не кликает в игре.
