# Dota Draft Assistant — контекст для Claude Code

Этот файл — передача контекста из долгого чата в Claude.ai, где проект был сделан.
Владелец проекта общается по-русски, коротко и прямо; отвечать по-русски, без воды.

## Что это

Windows-программа (C#/.NET 8, WPF) — помощник драфта Dota 2:
- в маленьком окошке справа сверху поверх игры показывает топ-3 героев для пика с причинами;
- после вашего пика показывает план на игру: старт, опасные враги, лёгкие цели, советы по предметам;
- по галочке показывает догадки о пиках соперников поверх их пустых слотов;
- в основном окне: сетка героев (★ основной / ♥ комфорт / ⊘ не играю), позиция и ранг, настройки окошка.

Распространение: GitHub Releases + Velopack с автообновлением. Друзья ставят по ссылке
`https://github.com/St1kr1k/DotaDraftAssistant/releases/latest/download/DotaDraftAssistant-Installer.exe`.
Каждый push в `main` = сборка в GitHub Actions = новая версия 1.0.N у всех. Поэтому не пушить мелочами без нужды.

## Жёсткие правила (не нарушать)

- Только анализ экрана (захват, CV, OCR, шаблоны) + официальный GSI Valve + открытые API.
  Никакого чтения памяти, инъекций, модификации клиента, перехвата трафика, автоматизации ввода. Это не чит.
- Подсказки в реальном времени — только по драфту. Советов посреди игры («не иди туда») не делать.
- Не выдумывать: причины — из статистики, советы — из фактов (свойства способностей, роли Valve).
  Неуверенность показывать словами «вероятно / возможно».
- Личную статистику игрока в оценку не добавлять (он хочет учиться новым героям).
- Подсказки про баны в основном приложении не предлагать: владелец отказался.
- Обходить SmartScreen / Smart App Control хитростями нельзя; только честная подпись (решено пока не делать).
- В файлы игры не лезть, кроме необязательного GSI-конфига.

## Архитектура (кратко, подробнее в ARCHITECTURE.md)

- `src/Domain` — модели: Hero, DraftState, PlayerProfile (позиция, ранг, отметки), PatchData, Scoring.
- `src/Application` — DraftPipeline (детектор → трекер → машина состояний → рекомендации → снимок),
  RecommendationService + evaluators, GamePlanService, EnemyPredictionService, StatsRoleInference.
- `src/Infrastructure` — захват GDI, Vision (PlayerBarGrid, DraftFrameAnalyzer, DraftTextReader OCR),
  Recognition (шаблоны портретов), GSI, Storage (загрузка и слияние данных), Players (OpenDota по нику).
- `src/Presentation` — WPF: App.xaml.cs (composition root), Main, Pages, Popup, Predictions.
- `tools/DataTool` — `fetch` (OpenDota), `fetch-stratz` (STRATZ GraphQL), `check-layout`, `add-template`.
- `.github/workflows/release.yml` — тесты → данные из релиза «data» (запасной путь: свой fetch) → публикация → vpk → установщик.
- `.github/workflows/data.yml` — мета без новых версий: каждые 3 ч проверка; новый патч — сразу, первые 3 дня патча —
  каждые 6 ч, потом раз в сутки. fetch + fetch-stratz + `DataTool pack` → пре-релиз `data`
  (data-meta.json, data-patch.zip, data-heroes.zip). Пре-релиз не мешает `releases/latest` и Velopack.
- `.github/workflows/stratz-probe.yml` — ручные пробные запросы к STRATZ (печатает схему или ответ в лог).

## Оценка героя

Score = 50 + 50·Σ(w·value·confidence)/Σw. Веса плавно переходят от «раннего» к «позднему» набору
по числу известных врагов (0..5), см. ScoringOptions:
- поздний пик: Counter 30, Lane 25, Synergy 10, Meta 10, Comfort 10, Pairs 5, RoleFit 5, Safety 5;
  ранний: Meta 15, Comfort 15, Lane 15, Counter 15, Safety 15, RoleFit 10, Synergy 10, Pairs 5;
- предлагаются все герои; отмеченные ★/♥ получают плюс через Comfort (★ 1.0, ♥ 0.7). Режим «только свои герои»
  (PoolOnly) был с 21.11 и убран 28.11 по просьбе владельца;
- фильтр: герой не предлагается, если на позиции < 15% его игр (без исключений для ★/♥);
- ScoringOptions.Version / RecognitionOptions.Version — при изменении дефолтов увеличивать,
  иначе у пользователей останутся старые значения из settings.json.

## Данные

- Приложение само подтягивает мету: `DataPackUpdater` (при запуске и каждые 3 ч) качает пакет из релиза `data`,
  если он новее, в `%APPDATA%\DotaDraftAssistant\data\<время>\`. Статистика подключается без перезапуска,
  но только вне драфта (0 подтверждённых пиков); новые герои (портреты) — после перезапуска.
  Выбор папок — `DataPackStore` (статистика: свежее встроенной; герои: только если появились новые).

- OpenDota: heroStats по бракетам, матчапы, лейны → позиции, items, abilities (dotaconstants).
- STRATZ (секрет STRATZ_TOKEN): по 4 группам рангов — позиции, матчапы с K/D, пары, исходы линий,
  стартовые закупки. Перед сохранением проверка симметрии (A против B + B против A ≈ 100%).
- ВАЖНО: STRATZ пускает токен максимум с 2 IP за 15 минут. Каждая сборка/проба в Actions — новый IP.
  STRATZ опрашивает только data.yml (release.yml — лишь если пакета нет). Не запускать пробу и data.yml подряд, ждать ~15 минут.
- STRATZ itemStartingPurchase: повторные копии (2-я ветка) помечены wasGiven=true — их НЕ отбрасывать.
- Стартовая закупка берётся по Легенда–Титан, набор до 600 золота.
- Если есть STRATZ по рангу, матчапы/позиции OpenDota для тех же героев не подмешиваются.
- Имена: OpenDota до сих пор зовёт OD «Outworld Devourer» → переименовано в загрузчике (RenamedHeroes).

## Распознавание драфта (выстрадано, не ломать)

- Цветная полоска игрока: у пустого слота — под портретом, у выбравшего героя — над ним (у края экрана),
  сдвинута наружу на 0.0725 шага. Ищутся обе строки (PlayerBarGridDetector), иначе после 5 пиков сетка уезжает.
- Портрет: от −0.49 до −0.12 шага от нижней полоски (ниже — подпись ранга «Страж III» в рейтинге).
- Шаблоны: портрет из данных, увеличенный ×1.2 (так Dota рисует арт в верхней панели).
- Пороги: MinScore 0.58, StrongScore 0.8. На реальных кадрах 2560×1440: герои 0.68–0.94, пустые ≤ 0.50.
- Затемнённый (наведённый, не выбранный) герой: СКО яркости < 25 → не пик.
- Внутриигровая полоска героев похожа на драфт: «драфт» с 8+ героями сразу или при GSI InGame/PostDraft игнорируется.
- Баны — только из чата («Запрещён герой: X.»). Чат читает en-US OCR, русское начало он видит как
  «3anpewéu repou» — это учтено в ParseBanLine.
- Свой слот — по нику (Steam persona) с расстоянием Левенштейна; смена слота только после 2 одинаковых прочтений.

## Отладка у владельца (Windows, 2560×1440, Dota на диске G:)

- Лог: `%APPDATA%\DotaDraftAssistant\draft-assistant.log` — каждый распознанный слот, сторона и источник,
  свой слот, баны из чата, топ-3 после каждого изменения, содержимое плана, результаты поиска игроков.
- Кадры: `%APPDATA%\DotaDraftAssistant\debug\draft_<дата>\<время>_picksN.png` (на каждом новом пике, 3 последних драфта).
- Распознавание удобно проверять на этих кадрах: скачать релиз (`gh release download -p "*-full.nupkg"`),
  взять `lib/app/data/heroes/*/portrait.png` и повторить алгоритм на Python/OpenCV.

## Открытые вопросы / идеи

- Проверено только на мониторе 2560×1440 владельца; у друзей с другим разрешением может требовать правки.
- Догадки о пиках соперников (OpenDota по нику): много скрытых профилей; не проверено в живом драфте, как ложатся иконки.
- Объяснения «почему» сейчас статистические; механика способностей (Hex снимает Blink и т.п.) — не сделано.
- Встроить ИИ (API Anthropic) для объяснений/разбора реплеев — обсуждали, не начато (ключ нельзя зашивать в программу).
- Разбор смертей по реплею после игры — идея, не начато (большой объём работы).
- Цифровая подпись: Microsoft Artifact Signing для частных лиц только США/Канада; вариант — Certum. Владелец пока отказался.
