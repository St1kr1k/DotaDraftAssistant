# 💎 Кристальная империя (Roblox, idle-тайкун)

Кристаллы добываются сами. Игрок строит и прокачивает генераторы, покупает улучшения,
ловит сверкающие кристаллы и перерождается ради звёздной пыли.

## Что есть
- **Участки на 8 игроков** вокруг лобби. У каждого свой парящий кристалл; купленные генераторы
  появляются в мире как постройки (10 разных), растут на каждом рубеже уровня и тянут к кристаллу светящийся луч.
- **10 генераторов**: Гном → Вагонетка → Бур → Шахта → Плавильня → Лазер → Портал → Дракон → Звёздная кузница → Чёрная дыра.
  Покупка ×1 / ×10 / ×100 / МАКС. Рубежи 10, 25, 50, 100, 150… — каждый удваивает добычу генератора.
- **63 улучшения**: по 5 на генератор (открываются по уровню) + общие множители, сила клика, частота бонусов, «Бригада».
- **Сверкающие кристаллы** раз в 1–2 минуты на экране: «Удача» (мгновенно много), «Лихорадка» (добыча ×7 на 30 с),
  «Клик-шторм» (клики ×50 на 15 с). Это и есть «подкликивать».
- **Перерождение** → звёздная пыль (+4% к добыче за каждую навсегда) и 9 звёздных улучшений, в т.ч. «Прораб» — автопокупка генераторов.
- **60 достижений** (+2% каждое), статистика, оффлайн-доход (50%, до 2 ч, улучшается), сохранение в DataStore,
  глобальное табло рекордов в лобби.

Темп (симуляция): 1M ≈ 5 мин, 1B ≈ 18 мин, первое заметное перерождение ≈ через час.

## Файлы
- `src/GameConfig.lua` — ModuleScript в ReplicatedStorage: весь баланс (цены, множители, достижения).
- `src/GameServer.server.lua` — Script в ServerScriptService: экономика, участки, бонусы, сохранение.
- `src/World.lua` — ModuleScript внутри GameServer: постройка мира, станций, табло.
- `src/GameClient.client.lua` — LocalScript в StarterPlayerScripts: интерфейс и анимации.
- `build.py` — собирает `CrystalEmpire.rbxlx` (открыть в Roblox Studio). Есть `default.project.json` для Rojo.

## Настройки в Studio
- Game Settings → Security → Enable Studio Access to API Services (для сохранений в Studio).
- Max players на сервере — 8 (по числу участков).
