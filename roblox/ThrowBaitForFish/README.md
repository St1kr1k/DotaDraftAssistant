# Throw Bait For Fish 🎣

Roblox-игра в духе Throw Food For Animals, только с рыбалкой: забрасываешь поплавок,
ловишь рыбу, она живёт в аквариуме на твоей базе и приносит деньги, даже когда ты не в игре.
Качаешь силу на турнике → бросаешь дальше → в дальних зонах рыба дороже и реже.

## Как открыть (первый раз)

1. Установи **Roblox Studio**: https://create.roblox.com → «Start Creating».
2. Скачай файл `build/ThrowBaitForFish.rbxlx` из этой папки репозитория.
3. Открой его двойным щелчком (или в Studio: File → Open from File).
4. Нажми **Play** (F5). Остров, причалы, аквариумы и всё остальное строятся скриптом при запуске,
   поэтому в режиме редактирования сцена пустая — это нормально.

Если что-то не работает — открой **View → Output**, скопируй красные строки и пришли мне.

## Как играть

- Иди на конец своего причала (светящийся круг «CAST HERE»), **зажми CAST** (или мышь / клавишу E) и отпусти.
  Чем дольше держишь, тем дальше бросок (до предела твоей силы).
- Когда над поплавком появится «!», **кликай**, чтобы быстрее вытащить рыбу.
- Рыба сама попадает в аквариум. Если он полон, самая слабая рыба заменяется более ценной.
- **Турник** у аквариума (или в центре острова): подойди и нажми E. Сила растёт сама, кликами — быстрее. Выход — прыжок.
- **Shop**: снаряды (x2…x64 к силе за повтор), наживки (удача), расширение аквариума.
- **Store**: донат.

Тест событий в Studio: напиши в чат `/event Storm` (или `GoldenHour`, `Frenzy`, `BloodMoon`, `MeteorShower`).

## Донат

Всё настраивается в `src/shared/Config.luau` (в Studio: ReplicatedStorage → Shared → Config).

| Товар | Цена (R$) | Тип |
|---|---|---|
| Тренировка x2 → x4 → x8 → x16 → x32 | 5 → 19 → 49 → 99 → 199 | геймпассы, лесенка: показывается только следующая ступень |
| Auto Cast (рыбалка в АФК) | 149 | геймпасс |
| x2 Cash | 99 | геймпасс |
| x2 Luck | 129 | геймпасс |
| +10 слотов аквариума | 79 | геймпасс |
| Lucky Cast / 10 Lucky Casts | 9 / 69 | расходник |
| Training Potion (x3 на 10 мин) | 15 | расходник |
| Server Luck x2 / x4 / x8 (15 мин всему серверу) | 19 / 49 / 99 | расходник |

Кнопка доната на турнике («⚡ Train x8 — only 49 R$») видна прямо во время тренировки: там она продаёт лучше всего.

Пока Id = 0, в Studio покупки выдаются бесплатно (для теста). Перед запуском:

1. File → **Publish to Roblox** (создать игру).
2. Game Settings → Security → включить **Enable Studio Access to API Services** (иначе не сохраняется прогресс).
3. На https://create.roblox.com/dashboard/creations → твоя игра → **Monetization → Passes** и **Developer Products**:
   создай товары с ценами из таблицы, скопируй их Id в `Config.luau` вместо `0`.
4. Опубликуй снова.

## Темп прогрессии (проверено расчётом)

До последней зоны: ~3 ч кликов или ~27 ч АФК без доната; с x4 — ~7 ч АФК; с x32 — ~50 мин АФК.
