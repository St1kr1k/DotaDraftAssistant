# Кристальный кликер (Roblox)

Простой incremental: кликаешь по гигантскому кристаллу → покупаешь улучшения → перерождаешься ради постоянного множителя.

- **Клик**: по кристаллу в мире или кнопкой «⛏ ДОБЫТЬ». Лимит 15 кликов/сек на сервере.
- **Улучшения** (9 шт.): за клик (кирка, перчатки, лазер), в секунду (гном, бур, шахта, портал, дракон), удача (крит ×10, до 50%). Цена растёт ×1.15–1.6 за уровень.
- **Перерождение**: с 1M кристаллов, сбрасывает всё, даёт +50% к добыче навсегда; каждое следующее ×5 дороже.
- **Сохранение** в DataStore, автосейв раз в минуту; оффлайн-доход 50% за время отсутствия (до 2 ч).

## Файлы
- `src/GameConfig.lua` — ModuleScript в ReplicatedStorage: апгрейды, цены, формулы (баланс правится тут).
- `src/GameServer.server.lua` — Script в ServerScriptService: мир, данные, клики, покупки.
- `src/GameClient.client.lua` — LocalScript в StarterPlayerScripts: интерфейс и анимации.
- `build.py` — собирает `CrystalClicker.rbxlx` (открыть в Roblox Studio). Есть и `default.project.json` для Rojo.

Для сохранения в Studio: Game Settings → Security → Enable Studio Access to API Services.
